# clanker-lab_v0.1
🤖 A local-first workshop for assembling purpose-built AI bootloaders.

🤖 CLANKER LAB
⚡ Build the machine you need.

Clanker Lab is a lightweight, local-first AI bootloader assembly system from Vespera Systems.

Instead of writing massive system prompts, Clanker Lab lets you assemble a purpose-built AI from modular components, then compile those choices into a portable bootloader for use with compatible LLMs.

Stop prompting. Start assembling.

🔧 How It Works

Choose an AI Chassis:

Researcher · Strategist · Operator · Developer · Writer · Tutor · Critic · Marketing · Blank

Then install and configure:

🧠 Temperament Chips — Direct, Curious, Skeptical, Analytical, etc.
⚙️ Reasoning Modules — First Principles, Systems Thinking, Devil's Advocate, Risk Analysis, and more.
📟 Behavior Directives — Define how your unit should operate.
🔧 Custom Directives — Fabricate your own operating rules.
🎛️ Linguistic Matrix — Tune detail, tone, criticism, and technical depth.
💾 Knowledge Bank — Add persistent context your unit should carry.

When you're finished:

⚡ COMPILE UNIT

Clanker Lab converts the configuration into a structured AI bootloader ready to copy or export.

🔒 Local-First

The current prototype runs entirely in your browser.

✅ No account
✅ No backend
✅ No API key
✅ No AI API calls
💾 Local browser storage
📦 TXT and JSON export
🌐 Single-file web application

Clanker Lab does not train or fine-tune an AI model. It builds structured behavioral instructions that can be carried between compatible AI systems.

🚀 Run It

Clone the repository and open:

index.html

That's it.

No installation or build process required.

🧬 Philosophy

AI configuration shouldn't feel like writing an instruction manual.

It should feel like assembling a machine.

Configure the chassis. Install the modules. Set the directives. Load the knowledge.

Then boot it.

🤖 Build the machine you need.
